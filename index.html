Bubble Sort in Mission Control

Every space operation receives an urgency score. LaunchPad uses Bubble Sort to compare neighboring mission tasks and move higher-priority operations toward the top of the queue.

01

Compare

Compare two neighboring mission tasks.

02

Swap

Swap them if the priority is incorrect.

03

Finalize

Repeat until the highest priorities reach the front.

ALGORITHM BUBBLE_SORT.JS 
for i = 0 to n - 1

    for j = 0 to n - i - 1

        if priority[j] < priority[j + 1]

            swap(priority[j],
                 priority[j + 1])

        end if

    end for

end for
