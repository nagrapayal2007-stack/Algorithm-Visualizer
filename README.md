# 🚀 LaunchPad – Space Mission Priority Engine

> **Every second matters.**

LaunchPad is an interactive **DSA-based web project** that demonstrates the practical application of the **Bubble Sort algorithm** through a futuristic space mission simulation.

The project assigns priority scores to different mission tasks and visually sorts them from **highest to lowest priority** using Bubble Sort.

---

## 🌌 Project Overview

In a space mission, different tasks can have different levels of urgency.

For example:

| Mission Task | Priority |
|---|---:|
| 🫁 Oxygen System Check | 95 |
| 📡 Communication Check | 72 |
| 🍱 Food System Check | 40 |
| 🔬 Research Module | 25 |

LaunchPad uses **Bubble Sort** to organize these tasks according to their priority.

The sorting process is displayed visually, allowing users to understand how the algorithm works step by step.

---

## 🎯 Objective

The main objective of this project is to make **Data Structures and Algorithms (DSA)** easier and more interesting to understand by connecting Bubble Sort with a real-world-inspired space mission scenario.

---

## 🧠 DSA Concept Used

### Bubble Sort

Bubble Sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them when they are in the wrong order.

In LaunchPad:

```text
Compare two neighboring mission tasks
              ↓
Check their priority scores
              ↓
Swap if the higher priority is behind
              ↓
Repeat until all tasks are sorted
