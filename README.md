LaunchPad – Space Mission Priority Engine is an interactive web-based DSA project that demonstrates the practical application of the Bubble Sort algorithm through a futuristic space mission simulation.

The project assigns priority scores to different mission tasks and visually sorts them from highest to lowest priority using Bubble Sort. It includes animated sorting, comparisons and swaps counters, speed control, mission generation, reset functionality, algorithm explanation, and a space-themed responsive interface.

Tech Stack: HTML, CSS, JavaScript
DSA Concept: Bubble Sort
Theme: Space Mission & Priority Management
